  <behavior>
The hook accepts a Word[] (pre-generated), two callbacks (onStart, onFinish), and exposes:
- words: Word[] — mutable state (chars updated with typed/state)
- currentWordIndex: number
- currentCharIndex: number
- started: boolean
- finished: boolean
- correctChars: number
- incorrectChars: number
- totalTypedChars: number
- handleKey(key: string): void — the main dispatcher

handleKey behavior cases (all input must be tested):

PRINTABLE CHAR (key.length === 1, key !== ' '):
  - If finished: return immediately (no input accepted)
  - If !started: set started=true, call onStart()
  - Compare key to words[currentWordIndex].chars[currentCharIndex].expected
  - If match: mark char state 'correct', increment correctChars
  - If no match: mark char state 'incorrect', increment incorrectChars
  - Set char.typed = key in both cases
  - Increment totalTypedChars
  - Advance currentCharIndex
  - If currentCharIndex === word.chars.length (end of last word): set finished=true, call onFinish()

SPACE (key === ' '):
  - If !started: return immediately (Space before first char does NOT start timer — R-004, R-057 deferred to Phase 3 but same logic applies)
  - If finished: return
  - Lock current word state ('correct' if all chars correct, 'incorrect' otherwise)
  - Increment currentWordIndex
  - Set currentCharIndex = 0
  - If new currentWordIndex >= words.length: set finished=true, call onFinish() (R-011)

BACKSPACE (key === 'Backspace'):
  - If finished: return
  - If currentCharIndex === 0: return immediately (no boundary crossing — R-009)
  - Decrement currentCharIndex
  - Reset the char at new currentCharIndex: { typed: null, state: 'untyped' }
  - Decrement totalTypedChars
  - If the decremented char was 'correct': decrement correctChars
  - If the decremented char was 'incorrect': decrement incorrectChars

ALL OTHER KEYS: silently ignored (Shift, Ctrl, Alt, Tab, etc.)

WPM calculation (exposed as computed value or via separate helper):
  calculateWPM(correctChars: number, elapsedSeconds: number): number
  - Returns Math.round((correctChars / 5) / (elapsedSeconds / 60))
  - Returns 0 if elapsedSeconds === 0

Accuracy calculation:
  calculateAccuracy(correctChars: number, totalTypedChars: number): number
  - Returns Math.round((correctChars / totalTypedChars) * 100)
  - Returns 0 if totalTypedChars === 0

Test cases (write these FIRST in RED phase):
  1. Initial state: currentWordIndex=0, currentCharIndex=0, started=false, correctChars=0
  2. Typing correct char: chars[0].state='correct', currentCharIndex=1, correctChars=1
  3. Typing incorrect char: chars[0].state='incorrect', incorrectChars=1
  4. Backspace after correct: char reverts to untyped, correctChars=0, currentCharIndex=0
  5. Backspace at position 0: nothing changes
  6. Space before typing: nothing changes, started=false
  7. Space after typing word: currentWordIndex=1, currentCharIndex=0
  8. First printable key: started=true, onStart called once
  9. Finishing last word: finished=true, onFinish called once
  10. Input after finished: all state unchanged
