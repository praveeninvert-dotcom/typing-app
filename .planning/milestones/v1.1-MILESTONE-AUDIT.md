## Tech Debt Summary

**No critical blockers. 5 deferred items across 2 phases.**

### Phase 04: UI Polish

1. **R-067 CSS gap (deferred by user):** `TextDisplay.module.css` `.container` is missing `overflow-y: auto`. The JS `scrollTo()` call is wired correctly in TextDisplay but has no visual effect without the CSS property. Phase 03 VERIFICATION marked R-067 satisfied (JS exists). Phase 04 plan 01 skipped the CSS fix per explicit user instruction. Fix: add `overflow-y: auto; max-height: 160px;` to `.container` in `TextDisplay.module.css`.

2. **Dead `soundEnabled` parameter:** `useKeystrokeSound` hook has an optional `soundEnabled?: boolean` parameter (defaulting `true`) that is never exercised now that the toggle was removed. No functional impact. Future cleanup: simplify hook interface by removing the optional parameter entirely.

3. **7 pending browser verifications (from 04-VERIFICATION.md):**
   - StarField stars visible and animated behind all screens
   - DifficultySelector amber selected state (rgba(180,100,0,0.35))
   - StatsBar 3-column grid layout with vertical dividers
   - TIME value turns red and pulses at 10 seconds
   - ResultOverlay WPM/ACC count-up animation
   - RETRY button auto-focus on result overlay mount
   - Sound plays on every keypress (no toggle)

4. **z-index spec deviation (minor):** Plan spec said screen content wrappers should be `z-index: 1 or above`. Current implementation relies on document order for layering. No visual issue; quit modal (z-index 100) and ResultOverlay (z-index 100/101) correctly float above.

### Phase 03: Sounds + Edge Cases + Animations + A11y

5. **ResultOverlay spring scale:** Phase 03 spec defined `scale: 0.92 → 1.0`. Phase 04 plan overrode to `scale: 0.8 → 1.0`. Implementation matches Phase 04 spec. R-065 is satisfied; the scale value is an aesthetic detail resolved by Phase 04.
