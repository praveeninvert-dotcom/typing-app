**Part A — useCountdown pause/resume:**

Read `hooks/useCountdown.ts` fully before modifying. Add `pause()` and `resume()` to the hook's return type. Use a `pausedRef = useRef(false)` to gate the interval tick.

Pattern: When `paused` is true, the setInterval callback does nothing (early return). `pause()` sets `pausedRef.current = true`, `resume()` sets it to false.

The hook's return type must expand:
```ts
interface UseCountdownReturn {
  timeLeft: number
  start: () => void
  pause: () => void
  resume: () => void
}
```

Implementation of pause/resume:
```ts
const pause = useCallback(() => { pausedRef.current = true }, [])
const resume = useCallback(() => { pausedRef.current = false }, [])
```

In the setInterval tick, add at the top: `if (pausedRef.current) return`

Return `{ timeLeft, start, pause, resume }`.

This is belt-and-suspenders: engine already ignores SPACE before start, but BACKSPACE at charIndex 0 also returns unchanged state. The explicit guard makes the intent clear.

**Caps Lock detection:** Detect via `e.getModifierState('CapsLock')` on keydown events on the hidden input AND via a separate `keyup` listener. Since the hidden input captures all keystrokes, update capsLockOn in `handleKeyDown`:
```tsx
setCapsLockOn(e.getModifierState('CapsLock'))
```

Also add a `useEffect` that listens on `window` for keydown/keyup to catch Caps Lock toggled outside the input:
```tsx
useEffect(() => {
  const handler = (e: KeyboardEvent) => {
    setCapsLockOn(e.getModifierState('CapsLock'))
  }
  window.addEventListener('keydown', handler)
  window.addEventListener('keyup', handler)
  return () => {
    window.removeEventListener('keydown', handler)
    window.removeEventListener('keyup', handler)
  }
}, [])
```

**Escape → quit confirmation:** In `handleKeyDown`, detect Escape key:
```tsx
if (e.key === 'Escape') {
  if (quitting) {
    // Escape dismisses (same as NO) — R-056
    setQuitting(false)
    countdown.resume()
    inputRef.current?.focus()
  } else if (engine.started && !engine.finished) {
    setQuitting(true)
    countdown.pause()
    // Focus YES button after state update
    setTimeout(() => yesButtonRef.current?.focus(), 0)
  }
  return
}
```

{quitting && (

    role="dialog"
    aria-modal="true"
    aria-labelledby="quit-title"
    onKeyDown={(e) => {
      // Focus trap: Tab cycles between YES and NO only
      if (e.key === 'Tab') {
        e.preventDefault()
        if (document.activeElement === yesButtonRef.current) {
